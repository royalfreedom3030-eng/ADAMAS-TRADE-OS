# ADAMAS-TRADE-OS

A modern React + TypeScript trading dashboard and operating-system-style workspace for market monitoring, portfolio tracking, and execution workflows.

## Features

- Multi-panel trading dashboard UI
- Real-time market watchlist and portfolio summary
- Order ticket and execution feed
- Risk, performance, and strategy cards
- Responsive desktop-first layout

## Tech Stack

- React
- TypeScript
- Vite

## Quick Start

```bash
npm install
npm run dev
```

The app runs on http://localhost:3000 by default.

## Production Build

```bash
npm run build
```
